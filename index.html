Lo primero

Configurá la perilla

De fábrica sube y baja el volumen de Windows y presionada hace mute. Con VIA le asignás lo que quieras a cada gesto: girar a la derecha, girar a la izquierda y presionar.

Paso a paso en VIA

  1. Con el teclado conectado, abrí usevia.app en Chrome o Edge. Firefox no puede comunicarse con el teclado.
  2. Tocá Authorize device y elegí el teclado. Si no aparece: Settings › Show Design tab y cargá el archivo JSON del Fibo F5, que provee el fabricante o el vendedor.
  3. En Configure, elegí la capa arriba del dibujo: 0 es la normal y 1 la que se usa mientras mantenés Fn.
  4. Tocá la perilla en el dibujo. VIA te muestra qué hace al girar a la derecha, a la izquierda y al presionar.
  5. Para cada gesto, elegí la función en las pestañas de abajo (Basic, Media…) o pegá el código de la receta en Any. Tocá un código a la izquierda para copiarlo.
  6. Se guarda en el teclado al instante, sin botón de guardar. Probalo en Pro Tools.

Según la versión de VIA, o si usás Keychron Launcher, los nombres de las pantallas pueden cambiar un poco; los pasos son los mismos.

Las tres recetas juntas

Capa 0: volumen. Capa 1 (con Fn): zoom. Para una tercera, asigná la tecla Menú a MO(2) en la capa 0 y poné el nudge en la capa 2: mientras mantenés Menú, la perilla hace nudge.

Commands Focus

Las recetas de zoom usan las letras R, T y E. En Pro Tools tiene que estar activo el botón a–z de la ventana Edit (Ctrl + Alt + 1).

Numpad en transporte

La receta de nudge usa + y − del numpad. Revisá que en Setup › Preferences › Operation el numpad esté en Transport.

Cómo se hace un macro

VIA › Macros › M0: escribí la combinación o grabala con Record. Después, en Configure › Macro, arrastrá M0 a la tecla.

Ojo con el layout españolEn este teclado el = está en Shift + 0 y los corchetes [ ] van con AltGr. Si Ctrl + = o Ctrl + [ ] no responden en Pro Tools, grabá el macro con Record usando las teclas reales y probalo antes de darlo por bueno. Mientras tanto: R / T para el zoom y el menú Window para Mix/Edit.

En el estudio

Los switches Red son lineales y silenciosos, pero igual alejá el teclado del micrófono cuando grabes voz en la misma sala.

Luces

Para sesiones largas, un efecto estático y tenue cansa menos la vista. Fn + Q cambia el efecto y Fn + W / S el brillo.

Mantenimiento

Es hot-swap: con la herramienta doble sacás tecla y switch sin soldar, con el cable desconectado. Trae 5 switches de repuesto.

Antes de la primera sesión

Paso 1 · Windows

Idioma del teclado

Configuración › Hora e idioma › Idioma y región: Español (España). Con «Latinoamérica» los símbolos no coinciden con las teclas.

Paso 2 · Pro Tools

Numpad como transporte

Setup › Preferences › Operation › Numeric Keypad: Transport, y Bloq Num encendido.

Paso 3 · Pro Tools

Commands Focus

Botón a–z arriba a la derecha de la ventana Edit, o Ctrl + Alt + 1. Así cada letra sola es un comando.

Paso 4 · Teclado

Fila F como teclas F

Si F1 sube el brillo o pausa la música, estás en la capa multimedia. Combiná con Fn o dejalo fijo en VIA.

Práctica 1

Modos y herramientas en la fila F

F1–F4 eligen el modo de edición, F5–F10 la herramienta. Apretá F6 y F7 juntas para la Smart Tool. Esc las recorre en ciclo.

Para no perderse

Shuffle mueve todo lo que viene después: cuidado si el material está sincronizado con video.

Grid (F4) apretado dos veces alterna entre grilla absoluta y relativa.

Trim (F6) apretado varias veces muestra sus variantes, como TCE para estirar en el tiempo.

Práctica 2

Editá un clip con una mano

Hacé clic en el clip para poner el cursor y usá las teclas como en Pro Tools con Commands Focus. Las flechas mueven el cursor.
